## 2024-05-15 - Array.find() Performance Bottleneck\n**Learning:** The application heavily relies on `surahData.find()` and `surahIndex.find()` inside loops and React renders. `surahData` and `surahIndex` are static arrays of 114 items. While 114 isn't huge, running O(N) array searches inside `.map()` loops or frequent re-renders blocks the main thread. Memory says we should use pre-computed maps `surahByName` or `surahByNumber` instead of `.find()`.\n**Action:** Create pre-computed lookup maps (e.g. Map objects) in `src/data/quranData.ts` for O(1) lookups by number or name. Replace `.find()` with `.get()` across the codebase to prevent main-thread blocking and improve rendering performance.
