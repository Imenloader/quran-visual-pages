## 2024-07-04 - Fast Array Backward Search and Map Lookups for Surahs
**Learning:** In React applications dealing with a moderate amount of data (like the 114 Surahs of the Quran), calling methods like `[...array].reverse().find()` creates unnecessary shallow copies and reverses the array in memory on each call, leading to performance bottlenecks when invoked repeatedly (e.g., resolving Surah context dynamically while scrolling). Furthermore, using `Array.find()` sequentially within `Array.map()` or inside frequent operations has O(N) complexity that becomes significant when rendering many elements.
**Action:** Replace `[...array].reverse().find()` with a backward traditional `for` loop for efficient end-to-front array traversal without allocation overhead. Implement ES6 `Map`s for pre-computed O(1) lookups based on Surah names, numbers, or stringified numbers. Export these Maps from the core data file (`src/data/quranData.ts`) and use `.get()` in components instead of `.find()`.
